# azzamprofile

Personal website of Azzam Aloudah. Data science and AI, Riyadh.

One static page in English and Arabic, dark, set in IBM Plex. No framework and no build step: `index.html` is the whole site.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

## Deploy

Hosted on Cloudflare Pages, connected to this repo. Every push to `main` publishes the site.

- Framework preset: None
- Build command: (empty)
- Build output directory: `/`
